Shared Folders

            

              Turned on folders are the same in every installation. Installations can opt out in
              their own Shared files tab.
            

          

          
        


        

        

          

            Location
            Loading...
          

          

            
            
            
          

        


        

          This drive can't use folder links (FAT32/exFAT, common on USB sticks). Shared folders are
          moved into an installation while it runs and moved back when the game closes. Two
          installations running at the same time can't use the same shared folder, so the second one
          uses its own for that session.
